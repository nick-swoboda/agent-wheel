# Convobus 0.1.5

Convobus 0.1.5 is a behavior-preserving reliability and safety release. It
keeps the same native interface, menu-bar behavior, project workflow, browser
GUI, CLI, stored data, and exact eleven-route catalog introduced in 0.1.4.

## Highlights

- Protects local conversation state with private permissions, atomic updates,
  and one bounded cross-process transaction lock.
- Authenticates state-changing localhost requests from the bundled native app,
  browser GUI, and CLI, and verifies the backend's exact root and launch identity.
- Requires exact composer replacement before Send and captures replies only
  from the selected provider session and route.
- Keeps Claude, ChatGPT, Cursor, and Grok route resolution strict, including
  ChatGPT Classic, Chat, Work, and Codex as separate routes.
- Removes the external Python dependency from Cursor session selection by using
  the embedded Node.js SQLite reader.
- Applies one revision-consistent native snapshot and rejects stale provider,
  project, status, card, and composer updates after a newer selection.
- Loads the provider catalog and cached projects immediately while session and
  Accessibility checks run asynchronously.
- Bounds HTTP bodies and provider output without truncating supported replies.
- Builds the universal app from a fresh explicit allowlist and verifies every
  staged binary and signature before publishing it.
- Uses Apache License 2.0 consistently across source, metadata, About, release
  documentation, and the bundled license.

## Install

1. Download `Convobus-0.1.5-macOS-universal.dmg`.
2. Verify it against `SHA256SUMS.txt` if desired.
3. Open the DMG and drag `Convobus.app` onto **Applications**.
4. Eject the disk image and open Convobus from Applications.

The app is self-contained for Apple-silicon and Intel Macs running macOS 13 or
newer. This public build is ad-hoc signed and is not Developer ID signed or
notarized, so macOS may require the documented **Open Anyway** first-launch
flow. No separate Node.js, Python, language runtime, or package manager is
required.

## Product parity

The release retains all four providers and eleven routes, strict no-fallback
routing, Add/Change Folder and Show in Finder, Settings and Accessibility,
filtered conversations, Send and Command-Return, the persistent menu-bar item,
close/reopen behavior, explicit Quit, legacy endpoints, and existing CLI forms.
Grok App remains intentionally unavailable.
