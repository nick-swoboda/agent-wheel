# Convobus 0.1.4

Convobus 0.1.4 completes the native macOS provider → project → exact-route
catalog with eleven isolated routes across Claude, ChatGPT, Cursor, and Grok.

## Highlights

- Separates ChatGPT Classic (`com.openai.chat`) from Chat and Work in the new
  ChatGPT app (`com.openai.codex`) and from the Codex CLI.
- Requires the exact new-app Chat surface before Chat reports attached; it never
  substitutes Work, Classic, or CLI.
- Captures new-app Chat replies through its macOS accessibility text markers and
  allows the rendered response to settle before completing the Convobus card.
- Keeps provider selection and background polling passive: Claude and ChatGPT
  are opened or focused only through an explicit attachment or send action.
- Loads the provider/project shell through a constant-time health check and
  stores native app state in Application Support, avoiding startup scans of
  protected folders and provider session stores.
- Includes Claude Chat, Cowork, Claude Code, and Claude CLI; ChatGPT Classic,
  Chat, Work, and Codex CLI; Cursor App and Cursor CLI; and Grok CLI.
- Keeps Grok App clearly unavailable rather than substituting Grok CLI.
- Preserves provider-specific projects, exact-route restoration, filtered
  conversations, the persistent menu-bar app, legacy APIs, and existing Work
  history.
- Refines the native window with a larger default canvas, more spacing, quieter
  single-route controls, Sent conversation states, and reliable rapid provider
  and project switching.
- Removes the redundant Conversation heading without collapsing the breathing
  room above the message cards.
- Adds a focused Settings page with Accessibility access, simple provider
  Found/Not Found status, version details, and the Apache License 2.0 notice.
- Keeps rapid provider and project choices authoritative over polling, presents
  conversation state as Sent or Waiting, and makes missing Accessibility or a
  missing project folder directly recoverable from the status control.
- Commits each provider or project at mouse-down, preventing an earlier context
  response from reclaiming the highlight during a fast second selection.
- Swaps cards and status atomically after selection, avoiding temporary Opening
  messages and intermediate status-color flashes; the fixed provider list no
  longer scrolls.
- Adds Change Folder and Show in Finder to every project’s right-click menu.
- Runs as a self-contained universal app on Apple-silicon and Intel Macs with
  macOS 13 or newer. No separate Node.js or language installation is required.

## Install

1. Download `Convobus-0.1.4-macOS-universal.dmg`.
2. Verify it against `SHA256SUMS.txt` if desired.
3. Open the DMG and drag `Convobus.app` onto **Applications**.
4. Eject the disk image and open Convobus from Applications.

This public build is ad-hoc signed and is not Developer ID signed or notarized.
macOS may block its first launch. After trying to open the app, follow
[Apple's Open Anyway instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)
only if you trust the download.

## Requirements

- macOS 13 or newer
- Apple-silicon or Intel Mac
- The provider apps or CLI tools for the routes you intend to use
- Accessibility permission for routes that interact with an app UI

Node.js 22.23.2 LTS is embedded inside the app and requires no separate install.

## Known release constraints

- The release is not notarized, so first-launch approval is expected.
- There is no automatic updater in this release.
- Grok currently provides a CLI route; an App route is intentionally unavailable.
