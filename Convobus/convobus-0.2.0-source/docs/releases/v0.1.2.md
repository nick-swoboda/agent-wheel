# Convobus 0.1.2

Convobus 0.1.2 is the initial open-source release of the native macOS provider →
project → route experience.

## Highlights

- Organize conversations by provider and project, then choose App or CLI and an
  exact provider-specific route.
- Switch providers and projects with stable single-click selection and restore
  each provider's most recently used project and route.
- Use strict routing for Claude Chat, Cowork, Claude Code, and Claude CLI;
  ChatGPT Work and Codex; Cursor and Cursor CLI; and Grok CLI.
- Keep Convobus available from the macOS menu bar after closing its window.
- Send through the production composer and keep conversation history filtered to
  the displayed context.
- Retain the existing local APIs, logs, CLI commands, card lifecycle, and folder
  binding behavior.

## Requirements

- Apple-silicon Mac
- macOS 13 or newer
- Node.js 26 or newer
- Accessibility permission for routes that interact with an app UI

## Install

Download `Convobus-0.1.2-macOS-arm64.zip`, unzip it, and move `Convobus.app` to
`/Applications`.

This public build is ad-hoc signed and is not Developer ID signed or notarized.
macOS may block its first launch. After trying to open the app, follow
[Apple's Open Anyway instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)
only if you trust the download.

Verify the archive against `SHA256SUMS.txt` before opening it.

## Known release constraints

- The downloadable build is Apple-silicon only.
- Node.js is required and is not embedded in the app bundle.
- There is no automatic updater in this release.
- Grok currently provides a CLI route; an App route is intentionally unavailable.
