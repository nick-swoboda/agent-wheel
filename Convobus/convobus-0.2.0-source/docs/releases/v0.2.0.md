# Convobus 0.2.0

Convobus 0.2.0 adds Loops to the native macOS app.

Each project has one Loops workspace. Start from **Loop** beside the message box
or the **+** beside **Loops**, enter what you want done, choose a Leader and an
optional Builder or Reviewer, then choose 1–50 cycles. Convobus remembers the
project's last team and cycle count.

Loops can pause for a human Leader, a correction, a one-turn user reply, or a
route that needs attention. Continuing a completed Loop requires another
explicit cycle choice. Closing the window keeps an active Loop running;
quitting checkpoints it for manual resume. Runs remain together in the
project's chronological Loops history; a run name is optional.

The direct provider and project experience is unchanged. Convobus still
supports four providers and eleven exact App and CLI routes without fallback.

## Install

1. Download `Convobus-0.2.0-macOS-universal.dmg`.
2. Open it and drag **Convobus.app** into **Applications**.
3. Open Convobus from Applications.

Convobus supports macOS 13 or newer on Apple silicon and Intel Macs. It is
self-contained and does not require Node.js or another runtime installation.
This build is ad-hoc signed and is not notarized.
